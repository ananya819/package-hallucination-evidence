# **Package Hallucination and Slopsquatting in Large Language Models (LLMs)**

## **Overview**

This repository contains the complete research artifacts, datasets, experimental outputs, and supporting evidence for our research study on **Package Hallucination and its relationship with Slopsquatting (Typosquatting) attacks in Large Language Models (LLMs)**.

The objective of this research is to analyze how LLMs generate non-existent, incorrect, or hallucinated software packages during code generation and investigate the potential security implications these hallucinations may introduce into modern software supply chains.

---

## **Research Objectives**

* Investigate the occurrence of **package hallucination** in LLM-generated code.
* Analyze patterns across multiple programming languages and models.
* Study the connection between hallucinated package names and **slopsquatting / typosquatting risks**.
* Evaluate whether hallucinated outputs may unintentionally create opportunities for supply-chain attacks.
* Build a structured dataset for reproducible analysis.

## **Research Methodology**

1. Prepare structured prompts for code generation.
2. Generate outputs using selected LLMs.
3. Extract package and dependency information.
